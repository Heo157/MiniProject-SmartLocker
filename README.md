# SmartLocker

- RFID / 4x4 Key / LCD / 서보 모터를 사용하여 구현한 스마트 사물함입니다.
- 사용자는 RFID 카드와 비밀번호, 두 가지 방식으로 인증을 할 수 있으며 직관적인 LCD 화면을 통해 시스템 상태를 확인할 수 있습니다.

### 프로젝트 목표
- **RFID 카드 인증** : 도어록에 RFID 카드를 접촉하면 자동으로 출입이 인증됩니다. 최초 사용 시 카드를 접촉하면 해당 카드가 마스터 키로 등록되어 이후에는 등록된 카드만 사용할 수 있습니다.
- **비밀번호 인증** : 키패드를 통해 4자리 비밀번호를 입력하여 문을 열 수 있습니다. 비밀번호는 언제든지 변경할 수 있습니다.
- **LCD** : 화면을 통해 현재 시스템 모드, 비밀번호 입력 상태, 출입 인증 결과 등 다양한 정보를 사용자에게 실시간으로 보여줍니다.
- **4x4 Key** : 비밀번호 입력 및 모드 전환에 사용됩니다.
    - 키패드 기능
        
        a - 비밀번호 변경<br>
        b - 모드 변경<br>
        c - 비밀번호 지우기<br>
        d - 비밀번호 확인 <br> # - 오픈 상태 일 때 잠금 
        
- 서보 모터 : 출입 인증이 성공하면 서보 모터가 작동하여 문을 자동으로 열어줍니다.
